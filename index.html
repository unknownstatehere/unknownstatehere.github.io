Политика конфиденциальности SupBot

Последнее обновление: 11 сентября 2026 года
SupBot — неофициальное расширение для продавцов FunPay. SupBot не является продуктом, подразделением или официальным расширением FunPay.

1. Общие положения

Настоящая Политика конфиденциальности описывает, какие данные обрабатывает браузерное расширение SupBot, для каких целей они используются и каким образом защищаются.

SupBot предназначен для автоматизации повседневной работы пользователя на сайте funpay.com, включая шаблоны сообщений, автоподнятие предложений, мониторинг сообщений, заказов и отзывов, а также системные уведомления.

2. Какие данные может обрабатывать SupBot

Для выполнения своих функций расширение может обрабатывать следующие категории данных.

  • Данные для аутентификации. SupBot может читать cookie golden_key, принадлежащую сайту funpay.com, когда это необходимо для выполнения функций расширения.
  • Личная коммуникация. Расширение может обрабатывать содержимое сообщений и информацию о диалогах FunPay, чтобы определять новые сообщения и предоставлять функции быстрых шаблонов и уведомлений.
  • Информация о заказах. SupBot может обрабатывать доступную на FunPay информацию о заказах, включая номер заказа, товар, цену, статус и связанную с заказом информацию, если она необходима для функций расширения.
  • Информация об отзывах. Расширение может анализировать информацию о новых или изменённых отзывах покупателей.
  • Идентификаторы пользователей. В процессе работы могут обрабатываться пользовательские имена, идентификаторы аккаунтов и другие идентификаторы, отображаемые на FunPay.
  • Содержимое сайта FunPay. SupBot считывает необходимые элементы страниц funpay.com для предоставления заявленных функций.
  • Настройки расширения. SupBot локально сохраняет пользовательские настройки, шаблоны сообщений, параметры уведомлений, настройки автоподнятия и техническое состояние функций расширения.

SupBot не запрашивает и не предназначен для обработки данных банковских карт, медицинских данных, точного местоположения пользователя или истории посещения сайтов за пределами FunPay.

3. Для чего используются данные

Данные используются исключительно для предоставления и улучшения основных функций SupBot, в частности:

  • отображения и использования быстрых шаблонов сообщений;
  • автоматического поднятия активных предложений;
  • проверки новых сообщений;
  • проверки новых заказов;
  • обнаружения новых или изменённых отзывов;
  • формирования системных уведомлений;
  • перехода из уведомления к соответствующему чату или заказу;
  • сохранения пользовательских настроек SupBot.

4. Где хранятся данные

Настройки SupBot, шаблоны сообщений и техническое состояние расширения хранятся локально средствами браузера пользователя.

SupBot не использует собственный сервер разработчика для хранения сообщений, заказов, отзывов, authentication cookie или других данных аккаунта FunPay.

Cookie golden_key управляется браузером и сайтом FunPay. SupBot получает к ней доступ только в рамках функций расширения и не передаёт её на сервер разработчика SupBot.

5. Передача данных

SupBot не продаёт пользовательские данные, не передаёт их рекламным сетям и не передаёт разработчику SupBot для создания профилей пользователей, рекламы или иных несвязанных целей.

Когда функции SupBot требуют взаимодействия с FunPay, данные передаются непосредственно между браузером пользователя и https://funpay.com/ по защищённому HTTPS-соединению.

Для отображения системных уведомлений необходимая информация может обрабатываться браузером и операционной системой пользователя локально на его устройстве.

6. Сторонние серверы и аналитика

Текущая версия SupBot не использует собственную систему аналитики, рекламные SDK или сторонние серверы для сбора пользовательских данных.

SupBot не использует пользовательские данные для персонализированной рекламы, ретаргетинга, определения кредитоспособности или кредитования.

7. Удалённый код

SupBot не загружает и не выполняет JavaScript, WebAssembly или другой исполняемый код с удалённых серверов.

Весь исполняемый код расширения поставляется непосредственно вместе с установленным пакетом расширения.

8. Доступ к сайту FunPay

Разрешение доступа к хосту ограничено доменом:

https://funpay.com/*

Данный доступ используется исключительно для функций SupBot, связанных с работой пользователя на FunPay.

Расширение не предназначено для отслеживания активности пользователя на других сайтах.

9. Хранение и удаление данных

Локальные настройки и данные SupBot могут храниться в браузере до тех пор, пока пользователь не удалит их самостоятельно, не очистит данные расширения или не удалит SupBot.

Данные, которые хранятся непосредственно компанией FunPay, регулируются правилами и политикой конфиденциальности FunPay и не контролируются SupBot.

10. Безопасность

SupBot ограничивает доступ только теми разрешениями, которые необходимы для заявленных функций. Взаимодействие с FunPay выполняется через HTTPS.

Разработчик принимает разумные технические меры, направленные на предотвращение несанкционированного доступа к пользовательским данным.

11. Ограниченное использование данных

Использование данных SupBot соответствует принципу ограниченного использования: данные применяются только для предоставления или улучшения заявленных пользовательских функций расширения.

Пользовательские данные не используются и не передаются:

  • для персонализированной или поведенческой рекламы;
  • для продажи пользовательских данных;
  • для определения кредитоспособности;
  • для целей, не связанных с основными функциями SupBot.

12. Изменения политики

Политика конфиденциальности может обновляться при изменении функций SupBot или способов обработки данных.

Актуальная версия политики всегда публикуется по тому же адресу. Дата последнего изменения указывается в начале документа.
